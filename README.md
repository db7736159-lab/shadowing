# 影子跟读 · 英语口语

一个纯前端的手机网页应用：听一句真人语速的示范，跟着读，立刻拿到逐词对照和三项分数；点句子里的任意单词能查意思。

没有账号、没有服务器、没有数据库。录音和进度只在这台手机的浏览器里。

## 怎么打开

手机浏览器（**Edge 或 Chrome**）打开当前隧道地址（每次重启会变，最新地址看会话里给的那条；也可以用 `tools/start.ps1` 自己开一个）：

> ⚠️ localhost.run 的免费隧道会**自己换域名**（一般几十分钟到几小时）。打开发现 404/502 就是换了，跟会话要新地址，或自己跑 `tools/start.ps1`。想彻底稳定就传到静态托管（见下面「长期用」）。

想固定地址，见下面「长期用」。

### 装到桌面（像 App 一样打开）

- **安卓 Edge**：右上角菜单 →「添加到手机」→「安装」
- **安卓 Chrome**：右上角 ⋮ →「添加到主屏幕」→「安装」
- 装好后有独立图标，全屏打开，练过的内容离线也能用

**现在有的场景**

- 旅行：机场值机（托运超重）、咖啡店点单、酒店入住
- 生活：看医生、看房租房、打电话预约
- 真人视频：TED 演讲《Try something new for 30 days》（3 分钟，854×480，原声 + 中英字幕对齐到句）

## 怎么练

1. **逐句跟读**（打分）：点「▶ 示范」听一遍 → 点「🐢 慢速」再听一遍 → 点「🎤 跟读这句」开口读 → 说完自动停，出分
2. **整段影子跟读**（不打分）：一段连着放，你同时跟着说。只录音，练完和示范对比着听。**建议戴耳机**，不然麦克风会录到示范的声音
3. **查词**：点句子里的任意单词，弹出音标和中文；弹层里可以按「☆ 收藏」进生词本
4. **收藏整句**：句子右下角「☆ 收藏这句」
5. **我的词句**：首页第二行进去，看生词和句子，点一条就跳回原句再练一遍，复习次数自动累计
6. 进度自动记在本机：每句的最好成绩、练到第几句、连续天数

## 换手机 / 换网址前先备份

设置页 →「导出备份」会下载一个 json（进度、生词、收藏、设置，**不含 Azure key**）。新设备上「导入备份」导回去就行。注意：**导入的视频文件不进备份**（太大），只备份视频的句子索引，换设备后要重新选一次视频。

## 分数怎么算

浏览器只能给到「听到了哪些词」，没有音标级数据，所以：

| 项 | 含义 | 算法 |
|---|---|---|
| 准确度 | 读对了多少词 | 对上的词 ÷ 原句词数 |
| 完整度 | 说到了多少词 | （对上 + 读成别的词）÷ 原句词数 |
| 流利度 | 语速是否接近自然 | 按 150 词/分算期望时长，偏离越多扣越多；太快太慢都提示 |
| 总分 | 0–100 | 0.45×准确 + 0.3×完整 + 0.25×流利 |

逐词对照：绿色的读对了，划掉的是漏读，红色波浪线是读成了别的词（下面会写「你读成 X」）。

**想要音素级评分**（哪个音不准、重音、语调）：设置里填 Azure Speech 的 key 和 region，就会切成微软的发音评估。不填就一直用免费的浏览器识别。key 只存在本机。

## 环境要求

| 需要 | 说明 |
|---|---|
| https 打开 | 否则浏览器不给用麦克风（隧道地址本身就是 https） |
| 语音识别 | 打分要靠它。浏览器识别（Web Speech）在国内经常"接口在、服务连不上"，所以**识别不出文字时会自动改用本机 Whisper**，连设置都不用改 |
| 识别引擎 | 设置里可切：浏览器识别 / 本机 Whisper / 只录音。豆包识别留了位置，还没接 |
| 麦克风权限 | 第一次点「跟读」会问，选允许 |
| 网络 | 第一次加载要下载界面和场景音频；之后有离线缓存 |

## 加自己的视频（不用改代码）

首页最下面「＋ 导入自己的视频 + 字幕」：

1. 选视频（mp4 / mov / 音频都行）
2. **没有字幕就点「🎙 没有字幕？在本机自动生成」**——Whisper 跑在手机里，不出声、不上传，第一次要先下 43MB 模型
3. 有字幕就选 SRT/VTT（可选，更快）
4. 中文字幕可选（自动生成的不带中文）
5. 起个名字 → 导入

视频存在浏览器的 IndexedDB 里，句子存在 localStorage 里，都不上传。导入完会出现在首页最前面，带「我的导入」标签，练法和内置包一样；进包页面可以删掉。

**自动生成字幕的实际情况**（实测）：

- 这台电脑上 60 秒音频识别用了 13.7 秒（约 4 倍实时）；手机上大约 1–2 倍实时，也就是 1 分钟音频等 1–2 分钟
- 第一次要下 43MB 模型，之后走浏览器缓存
- 只适合 3 分钟以内的片段
- 准确率：干净的讲解/对话不错；口音重、有背景音乐容易错
- 生成的是英文，**没有中文译文**
- **手机录的视频（HEVC 等编码）系统解不开**时，会自动用内置 ffmpeg 抠音频（第一次多下 31MB），最多处理前 5 分钟

字幕哪来：B 站/YouTube 的字幕下载工具导出的就是 SRT/VTT；本地视频的话，剪映、PotPlayer 之类也能导出。

**从别的 App 直接分享进来**：装成 PWA 后，这个应用会出现在安卓的分享菜单里。在相册、文件管理器、B 站里点「分享」→ 选「影子跟读」，视频就带过来了，再选一个字幕文件即可。

**注意**：长视频（20 分钟以上）在手机上解析和写入会慢一些；浏览器存储有上限，几个长视频之后可能要删旧的。

## 加自己的场景（写代码的方式）

1. 编辑 `tools/build_packs.py` 里的 `PACKS`，照着已有格式加一段（`role` 是 `staff` 或 `you`，`tip` 可留空）
2. 跑 `python tools/build_packs.py`：自动生成 `pack.json`、逐句 MP3，并把新词补进词典
3. 刷新页面就能看到

不想写代码也能加：直接手写一个 `packs/<id>/pack.json`，`audio` 指向 `s/01.mp3` 这类文件，然后把 MP3 放进去。

### 加一个 TED 演讲（真人视频，自动带中英文字幕）

```
python tools/build_talk_pack.py <ted.com 的 slug> [包 id]
# 例：python tools/build_talk_pack.py matt_cutts_try_something_new_for_30_days talk-30days
```

slug 是演讲网址里 `/talks/` 后面那段。脚本会自动：取视频 mp4 → 拉英文字幕和简体中文字幕轨道 → 按标点合并成句 → 按时间把中文对到每句 → 下载视频 → 生成 pack 并更新索引和词典。视频按句播放、可单句循环、可 0.7x。

注意：TED 的视频是 1200kbps，3 分钟约 27MB。挑演讲时尽量选短的，不然手机上第一次加载会等。TED 内容协议是 CC BY-NC-ND，自己学没问题，别拿去商用或公开发布。

## 长期用（固定地址、电脑可以关）

现在是「电脑开着 + 临时隧道」，地址会变。想固定：

- 把整个 `english-shadowing` 文件夹传到任意免费静态托管（Cloudflare Pages / Netlify / GitHub Pages / Vercel），拿到固定 https 域名
- 纯静态，不需要构建，直接把文件夹拖上去就行

`tools/start.ps1` 以后要重新开临时地址时用。

## 已知限制

- 浏览器识别偶尔会漏字、把连读听成别的词，这不是你读错了，重录一次通常就好
- 打分是「词级」不是「音素级」，`th` 读成 `s` 这种如果没改变单词，它发现不了；要更准就接 Azure
- 影子跟读不打分（一边放音一边说，麦克风会收到示范声音，分数没意义）
- 真人视频目前只有一个 TED 演讲包；对话类的真人视频还没找到能稳定下载的来源（YouTube 的下载工具在这台机器上装不上）
- 中文释义来自机器翻译，个别词偏书面或不准确
